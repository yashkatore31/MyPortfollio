# ✨ MyPortfolio

A **personal portfolio website** built using **Next.js**, **Tailwind CSS**, and **ShadCN UI**. Designed to showcase projects, skills, and experience with a modern and responsive interface.

> 🔗 **Live Demo:** [yash-katore-portfollio.vercel.app](https://yash-katore-portfollio.vercel.app/)
> 📂 **GitHub Repo:** [github.com/yashkatore31/MyPortfollio](https://github.com/yashkatore31/MyPortfollio)

---

## 🛠️ Tech Stack

* **Framework**: [Next.js](https://nextjs.org)
* **Styling**: [Tailwind CSS](https://tailwindcss.com)
* **UI Components**: [ShadCN UI](https://ui.shadcn.com)
* **Animations**: [Framer Motion](https://www.framer.com/motion)
* **Fonts**: Optimized with [next/font](https://nextjs.org/docs/app/building-your-application/optimizing/fonts)

---

## 🚀 Getting Started

To run the project locally:

```bash
git clone https://github.com/yashkatore31/MyPortfollio
cd MyPortfollio
npm install
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) in your browser.

---

## 📁 Project Structure

* `app/` – Application routes and layout
* `components/` – Reusable React components
* `lib/` – Utility functions
* `public/` – Static assets (images, icons, etc.)
* `styles/` – Global styles
